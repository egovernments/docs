# Public Finance

Public Finance Management or iFIX is an open-source fiscal information exchange solution. The application enables connected modules to exchange standardised fiscal events e.g. Demand, Receipts, Bills, and Payments. The fiscal event consists of attributes explaining the details of why, who, what, where and when it happened.&#x20;
